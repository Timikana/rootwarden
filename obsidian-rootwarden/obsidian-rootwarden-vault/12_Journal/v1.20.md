# v1.20.0 - 2026-05-05

Release "operations a distance" : reboot server depuis l'UI + auto-fix sshd AllowUsers + doc API rattrapee.

## Highlights

- **Bouton "Redemarrer"** dans `/update/` : `POST /reboot_server` (admin only). Double confirmation utilisateur, support `delay_minutes` (cap 24h via `shutdown -r +N`), audit log + webhook. Fallback `systemctl reboot` ou `/sbin/shutdown -r now`.
- **Auto-fix sshd AllowUsers complet** :
  - Auto dans `deploy_service_account` : si AuthenticationException sur le test rootwarden, patch sshd_config + retry.
  - Manuel via bouton "Autoriser sshd" dans `/adm/server_users.php` : `POST /sshd_allow_user`.
  - Helper `_ensure_sshd_allows_user` : idempotent, backup `.bak.rw`, validation `sshd -t`, rollback complet en cas d'echec.
  - Resout les serveurs hardenes type SRV-WEB:8568 qui bloquaient silencieusement.
- **OpenAPI v1.13 -> v1.19.0** dans `info.version`. **+6 routes documentees** : `/reboot_server`, `/server_user_keys`, `/server_user_remove_key`, `/sshd_allow_user`, `/wazuh/install_all`, `/wazuh/detect`. Total 136 paths.
- **Health check enrichi** : `/adm/health_check.php` teste 5 nouvelles routes (reboot, ssh-keys, sshd-allow, wazuh detect/install_all).
